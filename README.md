This Streamlit app explores healthcare resources across Lebanese districts

## Features
- Select a district
- Select a medical resource
- View the top 10 towns for the selected resource
- View the distribution of the selected resource across towns


## Files
- app.py
- Medical_Resources_Cleaned.csv
- requirements.txt
